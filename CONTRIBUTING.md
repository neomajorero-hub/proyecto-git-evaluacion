# Guía para contribuir

¡Hola! Para mantener el orden en este proyecto de Itahisa y Manu, sigue estas normas:

## Flujo de trabajo
1. **No hacer push directo a main**: Todos los cambios deben ir en ramas `feature-`.
2. **Pull Requests**: Es obligatorio abrir una PR para cualquier cambio.
3. **Revisión**: Al menos un compañero debe revisar y comentar el código antes del merge.
4. **Issues**: Cada PR debe estar vinculada a una Issue (ej. `Closes #1`).

## Estilo de commits
Usa mensajes descriptivos: `git commit -m "Acción: breve descripción"`.
